# Восстановление звонков Signal — 27.10.2026

Звонки восстановлены. Пользователь подтвердил: после ответа соединение устанавливается, звук есть.

## Причина и изменение

Оповещение о звонке, ответ собеседника, выдача ключей и защищённое сигнальное соединение работали. Передача звука зависала при установлении WebRTC-соединения.

На сервере с двумя публичными IP и внутренними сетями LiveKit использовал все адреса для медиатранспорта при заданном `node_ip: 177.3.212.182`. В `/etc/signal/livekit.yaml` добавлен фильтр адресов:

```yaml
rtc:
  node_ip: 177.3.212.182
  use_external_ip: false
  ips:
    includes:
      - 177.3.212.182/32
```

UDP-сокеты 7882 и 7883 теперь привязаны только к 177.3.212.182. Перезапущена служба `signal-media`. При следующем переносе IP нужно обновить также `rtc.ips.includes`.

Сквозное шифрование звонков сохранено. Рабочие настройки AmneziaWG, VPN-профили и старые входы VLESS не изменялись.
