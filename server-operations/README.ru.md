# Серверные операции Signal

Здесь сохранены исходники выполненных изменений сервера: перенос адреса и домена, добавление VPN, REALITY и AmneziaWG 3.1, изоляция административного доступа, безопасные обновления и исправление исходящего UDP-адреса AmneziaWG.

Текущий основной адрес сервера — 177.3.212.182, сайт — https://signal-on.ru. Исправление звонков сохранено в генераторе `deploy/config.mjs`: `rtc.ips.includes` содержит только основной IPv4 с маской `/32`. Подробная проверка — [SIGNAL-CALLS-FIX-2026-10-27.ru.md](SIGNAL-CALLS-FIX-2026-10-27.ru.md).

Сценарии рассчитаны на конкретные службы, пути и резервные копии. Перед повторным применением нужно сверить текущее состояние; начальные установщики нельзя повторно запускать поверх работающего развёртывания. Изменения маршрутов компьютера клиента не требуются. Старые входы VLESS сохраняются до переноса устройств.

Папки `private/`, `vendor/`, рабочие конфиги, ключи, базы, архивы, реальные профили и захваты диагностики исключены из Git. Доступы и приватные резервные копии остаются только на компьютере владельца и на сервере. Сценарии проверки создают собственные временные аккаунты и не должны вызывать реальных пользователей.
