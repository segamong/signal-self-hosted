# VPN Signal

Вход: `vpn.signal-on.ru:443` → основной IP `177.3.212.182`.
Выход в интернет: `177.3.212.182`.

В папке `private` находятся отдельные профили Windows и Android.
Откройте соответствующий `Signal-Windows.txt` или `Signal-Android.txt`, скопируйте строку целиком и импортируйте из буфера в клиент с поддержкой VLESS/XHTTP/TLS. На Android также можно отсканировать соответствующий PNG через импорт QR в клиенте. Для двух устройств используйте разные выданные профили.

На Windows для всех программ требуется режим TUN; на Android — системный VPN-режим. Тестовый локальный SOCKS-прокси, который использовался при проверке, остановлен. DNS, IPv6 и аварийное отключение интернета зависят от настроек выбранного клиента; после импорта проверьте внешний IP на самом устройстве.

Проверка сертификатов должна оставаться включённой. Если клиент не понимает XHTTP, нужен совместимый актуальный клиент; отключение TLS-проверки эту проблему не решает.

Используются TLS 1.3 и XHTTP через обычный HTTPS-сервер. Код генератора создаёт случайные идентификаторы устройств и непредсказуемый путь; XHTTP изменяет заполнение запросов и параметры переиспользования соединений. Это маскировка трафика, а не гарантия от блокировки IP. Шифрование реализуют проверенные библиотеки, собственный криптографический алгоритм не вводился.

Профили дают доступ к VPN. Не публикуйте их и не отправляйте QR в онлайн-декодеры.

Служба VPN: `signal-vpn`. Настройки: `/etc/signal-vpn/server.json`. HTTPS: `/etc/signal/Caddyfile`. Профили создаются собственным скриптом `prepare-vpn.ps1`; установку описывает `install-vpn.py`. Генератор намеренно отказывается перезаписывать существующие ключи.

Действующие профили 3x-ui не перегенерировались. Зашифрованный backup исходных настроек и согласованные SQLite-снимки сохранены на сервере в `/root/signal-maint-20261026T181257Z`; локальная копия этого backup не создавалась.

Серверная часть Signal переведена на новый IP и домен. Старые сборки приложения Signal, содержащие прежний IP в коде, требуют отдельного обновления клиента; это не относится к новым VPN-профилям.
