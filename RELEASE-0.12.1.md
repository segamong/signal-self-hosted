# Windows 0.12.1 — восстановление подключения после переноса сервера

Windows-клиент обращался к старому IP и показывал «Сервер пока не отвечает». Адрес API, событий, медиа и обновлений переведён на `https://signal-on.ru`. Проверка TLS, ограничения адресов, изоляция Electron и проверка целостности пакета сохранены. Установщик обновляет приложение с сохранением его данных; после смены домена может потребоваться повторный вход.

Генератор LiveKit теперь ограничивает ICE адресом `SERVER_IP/32`. Это сохраняет проверенное исправление зависания звонка после ответа на сервере с несколькими публичными и внутренними адресами. Сквозное шифрование звонков сохранено. Работа звонка со звуком после серверного изменения подтверждена владельцем.

В репозиторий добавлены исходники VPN-кабинета: VLESS + REALITY, AmneziaWG 3.1, VLESS/Trojan/VMess через XHTTP и TLS, варианты параметров, пулы и отдельный QR Xray-подписки. Добавлены серверные сценарии переноса адреса, ограничений административного доступа и исправления исходящего адреса AmneziaWG. Старые входы VLESS сохранены по решению владельца.

Приватные ключи, пароли, токены подписок, базы данных, реальные клиентские конфиги и диагностические захваты исключены. Исторические серверные сценарии требуют проверки перед повторным применением: они документируют конкретное развёртывание, а не универсальный установщик.

Проверка: TypeScript, производственная сборка интерфейса, две проверки адреса/генерации ICE и 26 тестов VPN-кабинета. Старый полный набор тестов приложения содержит сбои в проверках аудио и серверного API на неизменённых файлах; его нельзя считать успешно пройденным. Новый Android APK в этот выпуск не входит.
