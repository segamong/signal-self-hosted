# Сборка Сигнал 0.3.0 для Windows

Из корня проекта после установки зависимостей:

```powershell
pnpm run build
pnpm exec electron-builder --config electron-builder.yml --win --x64 --publish never
```

На Windows глубокий путь pnpm может превышать ограничение NSIS в 260 символов. В этом выпуске инструмент сборки установлен отдельным плоским деревом зависимостей в `work/windows-tools`; из корня проекта сборка запускалась так:

```powershell
node ../../work/windows-tools/node_modules/electron-builder/cli.js --config electron-builder.yml --win --x64 --publish never
```

Для повторения на другом компьютере можно разместить весь проект в коротком пути либо установить `electron-builder@26.15.3` через npm в короткий отдельный каталог. Версии Electron и приложения остаются заданными в проекте.

Установщик и переносная версия появляются в `../Windows`:

- `Signal-Setup-0.3.0-x64.exe` — полная установка для текущего пользователя, ярлыки, удаление через настройки Windows, обработчик `signal://invite/CODE`.
- `Signal-Portable-0.3.0-x64.exe` — запуск без установки. Переносная версия не регистрирует обработчик ссылок и не меняет автозапуск установленной копии; приглашение можно вставить в приложение.

В локальную оболочку входят `desktop`, готовый `dist`, `package.json` и Node-модуль `ws`. Исходники сервера, база, ключи и файлы развертывания исключены. У Electron есть отдельные системные библиотеки и лицензии; они необходимы для работы и остаются в сборке.

Значок PE/NSIS `build/icon.ico` содержит PNG-кадры 16, 20, 24, 32, 48, 64, 128 и 256 пикселей; `build/icon.png` имеет размер 512 × 512. Они получены из `public/signal.svg` с помощью `@resvg/resvg-js` 2.6.2 без перерисовки. Окно и трей используют отдельный `desktop/assets/icon.png`; копии иконок сборки также помещаются в каталог ресурсов. Лицензии клиентских зависимостей входят в `desktop/THIRD-PARTY-LICENSES.txt`, лицензии Electron/Chromium — отдельными файлами рядом с приложением.

## Состав 0.3.0

Общий клиент содержит отображение только username, входящие приглашения с принятием и отклонением, повторную отправку сразу после отказа, роли владельца/администратора/участника, настройки и модерацию каналов, профили с копированием username, редактирование и удаление сообщений, реакции и закрепления. Полноэкранная камера сохраняет пропорции. После F5 восстанавливаются комната, микрофон, камера и входящий звук с коротким разрывом связи; показ экрана включается заново с выбором источника.

## Манифест ручного обновления

Клиент читает только `https://13.143.172.92:9443/downloads/latest.json`. Файл содержит `version`, `filename`, `sha256`, `size`; для этого выпуска имя установщика — `Signal-Setup-0.3.0-x64.exe`. SHA-256 и размер в байтах нужно получать от окончательного файла установщика после сборки. Сначала размещают сам файл, затем соответствующий ему манифест. Изменение установщика после вычисления хеша требует обновить манифест. В этой инструкции публикация не выполняется автоматически.

Кнопка обновления выполняет проверку → загрузку → отдельную явную установку. Клиент принимает только стабильные версии `x.y.z` и строго соответствующее имя x64 Setup, отвергает редиректы и файлы больше 300 МиБ, проверяет фактический размер и SHA-256 и повторяет хеширование перед запуском. Файл загружается через `.partial` и переименовывается после проверки. Установщик запускается обычным способом для текущего пользователя; автоматического запуска и обхода предупреждений Windows нет. Portable может скачать тот же Setup и перейти к обычной установке.

Клиентам 0.2.x нужна одна ручная установка 0.3.0, поскольку кнопки обновления в старом исполняемом файле ещё нет.

## Настройки выпуска

В конфигурации используется `win.signExecutable: false`: сертификат подписи кода не предоставлен. `signAndEditExecutable` остается включенным, чтобы сохранить значок и сведения о версии. Windows может показывать предупреждение о неизвестном издателе. Для подписанного выпуска потребуется сертификат или настроенная служба подписи. [Документация параметров Windows](https://www.electron.build/v26/docs/api/app-builder-lib.interface.windowsconfiguration/).

NSIS работает в режиме `oneClick: true`, `perMachine: false`; приложение и переносной запуск не запрашивают административные права. Установщик сохраняет данные приложения при удалении. [Документация NSIS](https://www.electron.build/v26/docs/nsis/), [параметры переносной версии](https://www.electron.build/v26/docs/api/app-builder-lib.interface.portableoptions/).

Используется только архитектура x64. Работа в Windows 10/11 должна проверяться на соответствующих системах отдельно. Сборка не запускает тесты и ничего не публикует автоматически. [Конфигурация упаковки](https://www.electron.build/v26/docs/configuration/).

Статический просмотр и создание установщика не подтверждают UI, передачу медиа между физическими устройствами и нагрузку. Для функций 0.3.0 такие проверки не проводились. Сжатие WebRTC и ресурсы VPS/VPN продолжают ограничивать фактическое качество; десять HD-камер с тяжёлым экраном не подтверждены как стабильный режим.

Включены встроенная проверка целостности ASAR и запрет запуска Electron в качестве Node.js, параметров `NODE_OPTIONS` и инспектора Node. Это относится к упакованному исполняемому файлу; при локальной разработке используется исходный Electron из зависимостей.
