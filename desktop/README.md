# Сигнал 0.12.1 для Windows

Исправлен сброс флажка звука в выборе источника; повторное обновление списка сохраняет ручной выбор. Совместимый захват явно отключает исключение звука приложения. Изолированный системный захват доступен на Windows 11, сборка 22000+. На Windows 10 запуск со звуком в неподдерживаемом режиме предлагает выбрать совместимый захват, отключить звук или передавать отдельную вкладку из Chrome. Совместимый захват включает голоса звонка. Для игр доступен профиль до 1080p / 60 fps / 12 Мбит/с и приоритет плавности; фактические кадры зависят от устройства и сети.

Добавлен «Сигнал Clear» — локальный режим шумоподавления на открытой нейросети GTCRN. Выбор: настройки звонка → шумоподавление → «Сигнал Clear · нейросеть». Модель поставляется вместе с приложением; дополнительные ключи и подписки не нужны. Режим рассчитан на речь с верхней частотой около 8 кГц. RNNoise и обработка браузера остаются доступны. Лицензии включены в `THIRD-PARTY-LICENSES.txt`.

Вход: `desktop/main.cjs`. Интерфейс загружается из упакованного `dist` по адресу `app://signal/index.html`. Сервер приложения и медиа: `https://signal-on.ru`. Приложение использует обычную проверку TLS и не принимает недействительные сертификаты.

Возможности оболочки: отдельное окно, значок в трее, сворачивание в трей, сохранение размера окна и входа, автозапуск по выбору пользователя, один экземпляр приложения, глобальное сочетание `Ctrl+Shift+M`, ссылки `signal://invite/CODE`, выбор экрана/окна с миниатюрами. Системный звук включается отдельным флажком в окне выбора источника. Защищённый режим исключает голоса звонка на поддерживаемой Windows. На более ранней Windows 10 совместимый захват системного звука доступен по явному выбору; он может включать голоса участников. Микрофон передаётся отдельно.

Выпуск 0.10.0: ограниченная по высоте трансляция с участниками справа; отдельная громкость собеседника до 200%; независимая громкость трансляции и общая громкость воспроизведения. Режимы «Сигнал» и «Как в Discord» сохраняют собственные параметры. Доступны чувствительность, голосовая активация, рация с настраиваемой клавишей и задержкой отключения, эхоподавление, автоматическое усиление, браузерное шумоподавление и RNNoise. Клавиша рации работает при активном окне; проприетарные алгоритмы Discord/Krisp не используются. Звук трансляции требует выбора звука в окне захвата. Совместимый системный режим включается явно и может захватывать голоса звонка.

Общий интерфейс 0.3.0 показывает только username из аккаунта: чат, профили, список участников, камера и экран. Имена активных сессий SFU не используются как резервный вариант; до получения справочника виден текст «Участник». Приглашения по username принимаются и отклоняются во входящих; после отказа допустима немедленная отправка нового приглашения. Роли `owner`, `admin`, `member` определяют настройки канала, приглашения и модерацию. Владелец назначает администраторов и удаляет канал; модераторы управляют участниками, запретом передачи, закреплением и удалением сообщений. Администратор управляет обычными участниками. В чате доступны редактирование своих сообщений, удаление и реакции.

Камера разворачивается на весь экран кнопкой или двойным щелчком; кадр показывается целиком, выход — Esc, кнопка или повторный двойной щелчок. Перезагрузка страницы восстанавливает комнату после короткого разрыва связи. Состояние хранится в `sessionStorage` отдельно для вкладки и аккаунта: ID канала, пользовательские настройки микрофона, камеры и входящего звука. Токены и URL медиа в эту запись не помещаются. Ручной выход, удаление из комнаты и потеря членства очищают восстановление. Экран всегда требует нового явного выбора источника.

Portable определяется по `PORTABLE_EXECUTABLE_FILE`: он не регистрирует ссылки `signal://` и не меняет автозапуск установленной копии. Для этих функций нужна версия, установленная через `Signal-Setup`. Лицензии клиентских зависимостей находятся в `THIRD-PARTY-LICENSES.txt`; файл воспроизводимо собирается из установленных пакетов командой `node desktop/build-licenses.cjs`.

## Мост интерфейса

`window.signalDesktop` доступен только локальному интерфейсу. Все обработчики дополнительно проверяют окно, главный фрейм и локальный адрес отправителя.

- `getInfo()` → `{version, serverOrigin, platform, packaged, portable, screenAudioAvailable, screenAudioExcludesOwnAudio}`. Последний флаг подтверждает поддержку исключения звука приложения при захвате системного аудио на данной ОС.
- `requestApi('/api/...', body?)` → `{status, data}`; без `body` выполняется GET, с объектом `body` — POST. Разрешены только известные маршруты API.
- `subscribeEvents(callback)` → функция отписки. Отдаёт события сервера `presence`, `channels`, `message`, `message-updated`, `message-deleted`, `invitations`, `moderation`, а также `{type:'desktop-connection',connected,code?}`, `{type:'invite',code}`, `{type:'toggle-microphone'}`. Текущее состояние `presence`, `channels`, `invitations` повторяется после подписки; изменения сообщений и действия модерации передаются в момент получения без повторения. На приглашения следует подписываться до авторизации, сохраняя код до успешного входа.
- `windowAction('minimize'|'maximize'|'close')`.
- `getSettings()` / `setSettings({openAtLogin?,closeToTray?})`.
- `show()`.
- `getUpdateState()` / `checkUpdate()` / `downloadUpdate()` / `installUpdate()` → `UpdateState`.

`UpdateState` содержит `status` (`idle`, `checking`, `available`, `current`, `downloading`, `ready`, `error`), `currentVersion` и необязательные `version`, `progress` (0–100), `error`. Состояние также поступает через `subscribeEvents` как `{type:'desktop-update', ...state}`. Операции обновления запускаются кнопками интерфейса; установка требует отдельного нажатия после окончания загрузки.

Манифест читается только с `https://signal-on.ru/downloads/latest.json`. Ожидается `{version,filename,sha256,size}`, где версия имеет вид `x.y.z`, имя — строго `Signal-Setup-x.y.z-x64.exe`, SHA-256 — 64 шестнадцатеричных символа, размер не превышает 300 МиБ. HTTPS использует штатную проверку сертификата, перенаправления отклоняются. Поток записывается в `userData/updates/*.partial`, проверяется размер и SHA-256, затем файл переименовывается. Перед явным запуском установщика он хешируется повторно. Приложение завершается только после успешного старта установщика. Portable запускает тот же обычный установщик без тихого режима.

Для перехода с 0.2.x нужен один ручной запуск `Signal-Setup-0.3.3-x64.exe`: API обновления в старых клиентах отсутствует. В клиентах 0.3.x кнопка доступна в заголовке приложения и настройках и предлагает последовательные действия проверки, загрузки и установки.

Cookies авторизации остаются в постоянной сессии Chromium `persist:signal`. HTTPS-запросы делает основной процесс через `session.fetch` с `credentials:'include'`; WebSocket получает заголовок Cookie внутри основного процесса. Значения cookies, файловая система и произвольный доступ к сети через мост не предоставляются.

`getDisplayMedia` вызывает локальное модальное окно `app://picker`, которое предоставляет отдельный узкий мост выбора источника. Идентификатор выбранного источника проверяется по последнему списку `desktopCapturer`, затем предоставляется только исходному главному фрейму. Автоматический выбор экрана отсутствует.

`CallStage` принимает `initialPreferences`, `onPreferencesChange` и `onServerRemoved`. Сохраняется намерение пользователя: серверный mute и переподключение не перезаписывают выбранные состояния камеры и микрофона. Сервер продолжает проверять право публикации; запись настроек не отменяет запрет передачи. Ошибка доступа к устройству оставляет звонок подключённым. Ошибки с signaling URL, JWT и другими признаками токена заменяются безопасным текстом перед показом в интерфейсе.

## Пределы выпуска

Установщики не подписаны сертификатом издателя; приложение не обходит защиту Windows. Передача медиа на двух физических устройствах для 0.3.3 не проверена. Работа Windows 10 и 11 отдельно не подтверждена. WebRTC использует сжатие; исходное разрешение, 30/60 fps и высокий битрейт зависят от устройств и сети. Стабильность 10 камер с тяжёлой трансляцией на VPS вместе с VPN не подтверждена.
