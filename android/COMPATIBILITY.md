# Android 0.1.1 — совместимость

APK: Android 5.0+ (minSdk 21), targetSdk 37, без maxSdk. Включены ARM32 (`armeabi-v7a`), ARM64 (`arm64-v8a`) и `x86_64`. Для переписки нужен WebView Chromium 94+. Android 5.0/5.1 ограничены последним доступным им WebView 95, Android 6 — 106; заводского движка без обновлений недостаточно.

| Система | Голос, камера, просмотр и показ экрана | Звук других приложений при показе | Особенности |
| --- | --- | --- | --- |
| Android 5.0–5.1 / API 21–22 | Предусмотрены | Недоступен в системе | Совместимые службы, значок, подпись v1 и нативный TLS |
| Android 6–7.1 / API 23–25 | Предусмотрены | Недоступен в системе | Разрешения камеры/микрофона во время работы |
| Android 8–9 / API 26–28 | Предусмотрены | Недоступен в системе | Каналы уведомлений и отдельное разрешение установки APK |
| Android 10–11 / API 29–30 | Предусмотрены | Если источник разрешает запись | Системное подтверждение MediaProjection |
| Android 12–12L / API 31–32 | Предусмотрены | Если источник разрешает запись | Разрешение подключения Bluetooth |
| Android 13 / API 33 | Предусмотрены | Если источник разрешает запись | Разрешение уведомлений |
| Android 14–17 / API 34–37 | Предусмотрены | Если источник разрешает запись | Типы foreground service и новый запрос захвата при каждом старте |

«Предусмотрены» означает поддержку в исходниках и сборке. Это не результат испытаний на каждой версии Android. Физические телефоны в этой работе не подключались; реальные звонки, Bluetooth, VPN, производительность, нагрев и поведение фонового режима ещё требуют проверки на нужных устройствах. Качество кодека и частота кадров зависят от аппаратуры и сети.

## Решения для старых устройств

- API, сессия и чат WebSocket передаются через ограниченный адресом сервера нативный транспорт. Мост WebView доступен только главному фрейму доверенного origin. Он не принимает произвольные адреса или заголовки.
- Текущая TLS-цепочка сервера использует Let's Encrypt. В старые хранилища доверия добавлены подлинные публичные ISRG Root X1/X2 только для соединений с этим сервером. Проверка сертификата и имени сервера сохраняется.
- Интерфейс Android собирается отдельно для Chromium 94; добавлены CSS-замены динамических единиц высоты и селекторов `:has`.
- Выбраны совместимые с API 21 AndroidX Core 1.16.0, Activity 1.10.1, Lifecycle 2.9.4 и WebKit 1.14.0. LiveKit 2.29.0 и WebRTC не понижаются.
- Включены desugaring Java API, извлечение нативных библиотек для Android 5 и подпись APK v1 наряду с v2/v3.
- Ниже Android 5.0 текущий LiveKit/WebRTC не поддерживается. ABI x86 отсутствует у LiveKit UniFFI; включение одного фильтра ABI не обеспечило бы работающий звонок.

## Первичные источники

- [LiveKit Android SDK](https://github.com/livekit/client-sdk-android) — платформа и нативные зависимости.
- [AndroidX WebKit](https://developer.android.com/jetpack/androidx/releases/webkit) — изменение minSdk после 1.14.0.
- [Захват аудио Android](https://developer.android.com/media/platform/av-capture) — playback capture с Android 10.
- [Подпись APK v2 и старые системы](https://source.android.com/docs/security/features/apksigning/v2).
- [ISRG Root X1/X2](https://letsencrypt.org/certificates/) — публичные корневые сертификаты.
- [Desugaring Java API](https://developer.android.com/studio/write/java8-support#library-desugaring).
