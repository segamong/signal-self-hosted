# Сигнал 0.12.0 — звук и плавность демонстрации

## Звук

- В Windows окно выбора источника отражает включённую пользователем передачу звука и сохраняет ручное выключение при обновлении списка.
- Изолированный звук Chrome сохраняется при подтверждённом устройстве `loopbackWithoutChrome`, даже когда браузер не возвращает экспериментальное поле `restrictOwnAudio`.
- Уже изолированный системный звук и звук отдельной вкладки не открываются повторно через излишний `applyConstraints`.
- Совместимый режим действительно запрашивает `restrictOwnAudio: false` и не включает его обратно после выбора источника.
- Если источник не вернул звук, отметка остаётся в заголовке трансляции, а подробность доступна в настройках. Наличие дорожки не доказывает ненулевой сигнал от драйвера.

Исключение звука приложения в поставляемом Chromium требует Windows 11, сборка 22000+. На Windows 10 такой режим не запускает незаметно трансляцию без запрошенного звука: предлагается явный выбор другого режима. В браузере без поддерживаемого исключения доступен звук другой вкладки; системный звук требует совместимого режима. Этот режим может передавать голоса участников. При захвате экрана Chrome исключение может затрагивать звук всего браузера, а не только Сигнала.

## Игры

- Добавлен профиль «Игры · 1080p / 60 fps»: ограничение до 1080p, цель 60 fps, максимум 12 Мбит/с, движение и автоматический кодек. Профиль включается пользователем, текущие параметры не урезаются скрыто.
- Для движения WebRTC получает `maintain-framerate`; для текста остаётся `maintain-resolution`. Ранее и движение принудительно сохраняло разрешение ценой кадров.
- Автовыбор сначала учитывает плавные и эффективные кодеки, затем плавные. При неизвестной оценке игровой режим предпочитает H.264, затем VP8, затем VP9.
- Явный выбор кодека, исходного разрешения, 30/60 fps и битрейта сохранён.

Приоритет кадров допускает снижение разрешения при перегрузке. Частота 60 fps является целью. Загрузка GPU игрой, аппаратное кодирование, скорость сети и VPN влияют на результат; работа на устройствах пользователя в этом выпуске ещё не измерена. Сервер, база, шифрование, микрофон и алгоритмы шумоподавления не изменены.
